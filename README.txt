PC Context Builder v1.1.0
Windows 11 x64 / CPython 3.14 x64

Your PC. Understood by AI.

【目的】
Windows PCのシステム、ハードウェア、インストール済みソフトウェア、ローカル固定ドライブ、およびユーザーが選択したフォルダー／ファイルのメタデータを読み取り専用で収集します。結果を画面で確認し、明示的に選択・承認した情報だけをAIアシスタント向けコンテキストZIPにまとめます。

【起動】
1. ZIPを新しいフォルダーに解凍します。
2. 必要なら check_tool.bat を実行し、SELF-TEST PASS を確認します。
3. start.bat をダブルクリックします。メイン画面右上の言語メニューから简体中文、日本語、한국어、Englishを選択できます。選択言語は次回起動時も保持されます。
4. スキャン対象のローカル固定ドライブを選択します。
5. スキャン完了後、各タブの結果を確認します。
6. ソフトウェア・フォルダー・ファイルのメタデータは初期状態で除外されています。必要な項目だけ選択します。
7. 最終確認後、出力先を選択してZIPを作成します。

【出力】
- ファイル名：PC_Context_Pack_YYYYMMDD_HHMMSS.zip
- ZIP内のルートフォルダー：PC_Context_Pack/
- PC概要、選択されたソフトウェア・ストレージ・ファイル索引、除外項目サマリー、スキャンレポートを含みます。
- ZIPは暗号化されません。共有前に必ず内容を確認してください。

【重要な既定値】
- PC基本情報とドライブ一覧は初期選択されています。ソフトウェア・フォルダー・ファイル一覧は初期状態で除外です。
- ファイル一覧は1ページ500件、フォルダー一覧とソフトウェア一覧は各250件です。
- ファイル名・パス・ソフトウェア名は個人情報やプロジェクト名を含む可能性があります。
- .env、credentials、secret、password、token、API key、秘密鍵、ADB keyなどの機微候補は初期状態で除外します。
- 機微候補を手動で含めた場合は最終確認をもう一度表示します。

【安全設計】
- すべてのスキャン・ZIP生成はPC内で実行します。自動アップロードやネットワーク送信はありません。
- 読み取り専用です。元ファイル、フォルダー、レジストリ、Windows設定を変更しません。
- 文書、画像、動画、音声などのファイル本文・画素・音声は読み取りません。
- パスワード、Cookie、ログインセッション、APIキー、アクセストークン、SSH秘密鍵、Windows資格情報は取得しません。
- Windows、Program Files、ProgramData、AppDataなどのシステム／アプリ領域、クラウド同期フォルダー、キャッシュ・開発依存フォルダーはファイル走査から除外します。
- シンボリックリンク、ジャンクション、再解析ポイント、隠し／システムファイル・フォルダーは辿りません。
- CSV出力では表計算ソフトの数式として解釈され得る先頭文字をテキスト化します。機微ディレクトリはパス構成要素と一般的なクラウド同期ルートで除外しますが、検出は完全ではありません。

【スキャン上限】
最大10分、最大150,000ファイル、30,000フォルダー。上限到達やアクセス拒否は部分スキャンとして記録します。

【依存関係】
Python標準ライブラリとWindows PowerShell CIMを使用します。外部pipパッケージは不要です。start.bat はCPython 3.14 x64を確認して起動します。
